# UPI Transaction Analytics Dashboard using Excel

## Project Overview
This project analyzes UPI transaction data using Microsoft Excel to understand transaction performance, payment status, UPI app usage, transaction types, and suspected fraud patterns.

## Objectives
- Analyze total transactions and transaction amounts.
- Identify successful and failed transactions.
- Understand UPI app usage and transaction types.
- Analyze suspected fraud transactions.
- Present insights through an interactive dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Cleaning
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Transactions
- Total Transaction Amount
- Total Cashback
- Success Rate
- Suspected Fraud Transactions

## Dashboard Features
- Interactive filters using slicers
- Transaction status analysis
- UPI app usage analysis
- Transaction type analysis
- Fraud transaction analysis
- Interactive charts and KPI cards

## Project Workflow
1. Import the UPI transaction dataset.
2. Clean and prepare the data.
3. Create PivotTables for analysis.
4. Build charts and KPI cards.
5. Add interactive slicers.
6. Create the final Excel dashboard.

## Project Outcome
The dashboard helps users understand UPI transaction trends, payment success rates, app usage, and suspected fraud patterns.
